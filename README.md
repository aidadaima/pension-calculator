# lims-instrument-scan

仪器扫码领用 —— 小程序扫码申请领用 + 后端接口。

仓库刚建，内容会陆续放进来。

## 计划放什么

| 目录 | 内容 |
| --- | --- |
| `miniprogram/` | 微信小程序端：扫码领用页、仪器列表页 |
| `server/` | 后端接口：单文件 ashx（IIS + .NET Framework，可直接丢到站点目录跑） |
| `docs/` | 接口说明、部署说明、自测记录 |

## 这套东西解决什么

实验室仪器台账里，`LimsInstrument.Yqtestint2` 记状态（0/NULL 未领用、10 使用中）、
`yqcheckstr2` 记使用人。人拿手机扫仪器上的二维码 → 查到这台仪器 → 点申请领用 →
接口把状态和领用人写回这两个字段；用完了点归还，状态回到未领用。

并发靠「把状态判断写进 UPDATE 的 WHERE」，两个人同时扫同一台，只有一个能成功。
