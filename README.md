# 退休金测算

一个**单文件网页工具**：按现行政策估算你什么时候能退休、退休后每月能领多少养老金、钱是哪几部分组成的。

## 怎么用

下载 `pension-calculator.html`，双击用浏览器打开就行。

- 不需要联网、不需要安装任何东西
- 输入的信息只在你自己的浏览器里计算，不上传、不保存
- 手机浏览器也能打开，竖屏会自动变成上下布局

## 能算什么

**输入**：参保身份（男职工 / 女干部·灵活就业 / 女工人）、出生年月、开始缴费年月、视同缴费年限、平均缴费指数、退休地计发基数、个人账户现有余额、记账利率、过渡性养老金系数，以及一个弹性退休滑块（提前或延后最多 3 年）。

**输出**：

| 项目 | 说明 |
| --- | --- |
| 每月养老金 | 基础养老金 + 个人账户养老金 + 过渡性养老金，带占比条 |
| 法定退休时间 | 已按渐进式延迟政策算出实际退休年月和退休时年龄 |
| 缴费年限 | 与当年最低缴费年限对比，不够会提示差多少年 |
| 替代率 | 月养老金占退休前缴费工资的比例 |
| 回本时长 | 个人缴费本金按这个金额多久领回来 |
| 25 年曲线 | 每年月领额（按年上调 2%）与累计领取总额 |

## 算出来的数是怎么来的

```
月养老金 = 基础养老金 + 个人账户养老金 + 过渡性养老金

基础养老金    = 计发基数 × (1 + 平均缴费指数) ÷ 2 × 缴费年限 × 1%
个人账户养老金 = 个人账户储存额 ÷ 计发月数
过渡性养老金  = 计发基数 × 平均缴费指数 × 视同缴费年限 × 过渡系数
```

计发月数按官方公布节点取值：50 岁 195、55 岁 170、58 岁 152、60 岁 139、63 岁 117，中间月份做线性插值。

## 政策口径

| 规则 | 内容 |
| --- | --- |
| 渐进式延迟退休 | 自 2025-01-01 起，原 60 岁男职工、原 55 岁女职工每 4 个月延迟 1 个月，15 年分别延迟至 63 岁、58 岁；原 50 岁女工人每 2 个月延迟 1 个月，延迟至 55 岁 |
| 最低缴费年限 | 2029 年底前退休仍为 15 年；2030 年起每年提高 6 个月；2039 年起固定 20 年 |
| 弹性退休 | 达到最低缴费年限可自愿提前最多 3 年（不得低于原法定年龄），也可与单位协商延后最多 3 年 |

依据：全国人大常委会《关于实施渐进式延迟法定退休年龄的决定》及国务院《关于渐进式延迟法定退休年龄的办法》（2025 年 1 月 1 日施行）、《中华人民共和国社会保险法》。

## 算法验证过

核心算法有 16 条断言，全部通过，其中直接对齐了官方公布的例子：

- 1972 年 9 月出生的男职工 → 法定退休 62 岁
- 1980 年 11 月出生的女工人 → 法定退休 53 岁（2033 年退休，最低缴费 17 年）
- 1965 年 1–4 月出生的男职工 → 延迟 1 个月；1977 年起延迟封顶 36 个月

延迟月数的算法：`clamp(ceil((原退休月距 2025-01 的月数 + 1) ÷ 步长), 0, 上限)`，男职工与女干部步长 4 个月、上限 36 个月，女工人步长 2 个月、上限 60 个月。

## 边界要说清楚

这是按公开政策做的**估算**，不是社保经办机构的核定结果。各省计发基数、过渡系数、视同缴费年限认定、个人账户记账利率都存在差异，实际金额以参保地核定为准。
